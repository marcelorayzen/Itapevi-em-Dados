# Estratégia de código aberto

- O código é licenciado sob Apache-2.0.
- O repositório é aberto e projetado para reutilização, sem presumir que dados e fontes tenham a mesma licença do código.
- Credenciais, dados pessoais e configurações privadas não devem ser versionados.
- Contribuições ocorrem por issue e pull request, com revisão antes de integração.
- Dependências devem ter licenças inventariadas antes de releases estáveis.

Abrir o código não autoriza replicar, redistribuir ou processar dados de uma fonte sem verificar seus termos, finalidade, LGPD e responsabilidade institucional.
