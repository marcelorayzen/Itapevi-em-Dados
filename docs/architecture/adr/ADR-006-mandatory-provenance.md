# ADR-006 — Proveniência obrigatória

- **Status:** Proposta
- **Contexto:** transparência pública exige que qualquer conclusão seja verificável.
- **Decisão:** exigir fonte, registro, artefato, localizador e data de coleta para fatos; derivadas mantêm também lineage de processamento.
- **Consequência:** dados sem proveniência ficam em quarentena ou são exibidos como não verificados, nunca como fato consolidado.
