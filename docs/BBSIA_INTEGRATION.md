# Integração BBSIA

## Contribuição inicial

A contribuição inicial é documental e técnica: metadados do repositório, arquitetura, catálogo de conectores, documentação institucional e matriz de maturidade do protótipo.

## Evolução possível

Datasets estruturados e APIs poderão ser avaliados futuramente somente após validação da licença da fonte, LGPD, qualidade, atualização, proveniência e governança. Este repositório não declara uma API pública existente.

Quando aplicável, os formatos preferenciais são JSON, CSV, JSON-LD e OpenAPI. A adoção de qualquer formato depende do caso de uso e da governança aprovada.
