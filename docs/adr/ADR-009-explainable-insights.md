# ADR-009 — Insights explicáveis e auditáveis

- **Status:** Aceito
- **Contexto:** análises públicas podem ser interpretadas como afirmações sobre pessoas ou órgãos.
- **Decisão:** insights futuros devem mostrar regra, período, cobertura, evidências e limitações; não podem ser acusatórios.
- **Consequências:** aumenta exigência de dados e revisão, preservando auditabilidade.
- **Alternativas consideradas:** resumos sem evidências; rejeitados por comprometer confiança.
