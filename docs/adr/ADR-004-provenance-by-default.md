# ADR-004 — Provenance por padrão

- **Status:** Aceito
- **Contexto:** transparência exige origem verificável para fatos e respostas.
- **Decisão:** manter fonte, URL/referência, data de coleta, hash quando disponível, transformação e versão.
- **Consequências:** dados sem evidência não são apresentados como consolidados.
- **Alternativas consideradas:** citar fonte apenas na interface; rejeitada por não permitir auditoria de pipelines.
