# ADR-008 — Separar código aberto e governança de dados

- **Status:** Aceito
- **Contexto:** licença de software não transfere direitos sobre fontes e dados públicos.
- **Decisão:** licenciar o código sob Apache-2.0 e avaliar dados, fontes e derivados por licença, termos e LGPD próprios.
- **Consequências:** publicação de novos datasets exige validação separada.
- **Alternativas consideradas:** aplicar a licença do código a todo conteúdo; rejeitada por ser juridicamente inadequada.
