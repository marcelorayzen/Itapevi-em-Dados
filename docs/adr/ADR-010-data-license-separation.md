# ADR-010 — Separação entre licença do código e licença dos dados

- **Status:** Aceito
- **Contexto:** o código pode ser aberto sob Apache-2.0, mas dados públicos, documentos, APIs, PDFs, portais e dados derivados podem ter regras próprias.
- **Decisão:** separar explicitamente a licença do código, a licença ou termos da fonte de dados e as condições de redistribuição de dados derivados.
- **Consequências:** nenhum conector poderá assumir que dado público é automaticamente livre para redistribuição; cada fonte precisa de registro de origem, termos e condição de uso.
- **Alternativas consideradas:** aplicar a licença do código aos dados; rejeitada por ser juridicamente e operacionalmente incorreta.
