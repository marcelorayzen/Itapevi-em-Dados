## Limites de transparência

O repositório aberto contém código e documentação pública. Ele não contém credenciais, artefatos brutos, dados pessoais, planos de operação, registros internos de avaliação nem arquivos locais de fontes. A licença Apache-2.0 do código não altera os termos de uso de dados, documentos ou APIs de terceiros.
